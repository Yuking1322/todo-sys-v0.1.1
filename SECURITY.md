# Security Policy

## Supported Versions

Current maintained versions for security updates:

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅ |
| < 0.1.0 | ❌ |

## Reporting a Vulnerability

Please do not report security vulnerabilities in public Issues.

Use the repository Security page and click "Report a vulnerability" (private channel).
Include:

1. Vulnerability type and impact
2. Minimal reproduction steps
3. Affected endpoints/files/configuration
4. Suggested fix (if available)

Target response timelines:

1. Acknowledgement within 72 hours
2. Initial assessment within 7 days
3. Coordinated disclosure after a fix is ready

If a secret is exposed, revoke and rotate it immediately before reporting.
